# Mr.PCPicker 백엔드-프론트엔드 연결 가이드

## 🚀 아키텍처 개요

Mr.PCPicker는 Django REST framework 기반의 백엔드와 Vue.js 기반의 프론트엔드로 구성된 SPA(Single Page Application)입니다. 백엔드와 프론트엔드는 RESTful API를 통해 통신합니다.

## 🔌 연결 방식

### 1. API 통신
- **프로토콜**: HTTP/HTTPS
- **인증 방식**: JWT(JSON Web Token) 기반 인증
- **CORS**: 백엔드에서 프론트엔드 도메인에 대한 CORS 허용 설정이 필요

### 2. API 엔드포인트
기본 URL: `http://localhost:8000/accounts/api/`

| 엔드포인트 | 메서드 | 설명 |
|-----------|--------|------|
| `/token/` | POST | 로그인 (JWT 토큰 발급) |
| `/token/refresh/` | POST | JWT 토큰 갱신 |
| `/register/` | POST | 회원가입 |
| `/logout/` | POST | 로그아웃 |
| `/user/` | GET, PUT | 사용자 정보 조회/수정 |
| `/change-password/` | POST | 비밀번호 변경 |
| `/user/delete/` | DELETE | 회원 탈퇴 |

## 🔧 개발 환경 설정

### 백엔드 (Django)
1. 가상환경 설정 및 활성화
```bash
python -m venv venv
.\venv\Scripts\activate
```

2. 의존성 설치
```bash
pip install -r requirements.txt
```

3. 데이터베이스 마이그레이션
```bash
python manage.py migrate
```

4. 개발 서버 실행
```bash
python manage.py runserver
```

### 프론트엔드 (Vue.js)
1. 프론트엔드 디렉토리로 이동
```bash
cd frontend/pcpicker-project
```

2. 의존성 설치
```bash
npm install
```

3. 개발 서버 실행
```bash
npm run dev
```

## 🔄 CORS 설정
백엔드 `settings.py`에 다음 설정이 필요합니다:
```python
INSTALLED_APPS = [
    # ...
    'corsheaders',
    # ...
]

MIDDLEWARE = [
    # ...
    'corsheaders.middleware.CorsMiddleware',
    'django.middleware.common.CommonMiddleware',
    # ...
]

# CORS 설정
CORS_ALLOWED_ORIGINS = [
    "http://localhost:3000",  # 프론트엔드 개발 서버 주소
    "http://127.0.0.1:3000",
]

CORS_ALLOW_CREDENTIALS = True
```

## 🔒 인증 흐름
1. 사용자가 로그인 폼 제출
2. 프론트엔드에서 `/accounts/api/token/`으로 POST 요청
3. 성공 시 access/refresh 토큰 수신
4. access 토큰을 로컬 스토리지에 저장
5. 이후 요청 시 헤더에 토큰 포함
   ```javascript
   Authorization: Bearer {access_token}
   ```
6. 토큰 만료 시 `/accounts/api/token/refresh/`로 갱신

│   │   └── views.py      # 뷰 로직

    └── pcpicker-project/

## 🔍 문제 해결
1. **CORS 오류 발생 시**
   - 백엔드 CORS 설정 확인
   - 프록시 설정 또는 CORS 헤더 확인

2. **인증 오류 시**
   - 토큰이 유효한지 확인
   - 헤더에 올바르게 토큰이 포함되었는지 확인

3. **API 요청 실패 시**
   - 백엔드 서버가 실행 중인지 확인
   - API 엔드포인트가 정확한지 확인
   - 네트워크 탭에서 요청/응답 확인
```
