### 1. 502/500 에러 및 타임아웃 해결
- **문제**: 외부 API(OpenAI, SerpApi) 응답 지연 시 서버 타임아웃 발생 및 환경변수 미인식으로 인한 502/500 에러 발생.
- **해결**: 모든 API 호출부에 `timeout`을 설정하고, API 호출 실패 시에도 시스템이 중단되지 않고 일반 구글 검색 결과(`fallback_url`)를 반환하도록 예외 처리를 강화하여 서비스 가용성을 확보함.

### 2. 데이터 누락(# 💻 GMS (Global Matching Service) - Computer Recommendation System

이 프로젝트는 사용자의 자연어 요구사항을 분석하여 최적의 컴퓨터 제품을 추천하고, 실시간 최저가 및 브랜드별 공식 홈페이지 링크를 매칭해주는 **AI 기반 추천 엔진** 백엔드 시스템입니다.


## 🛠 주요 기술 스택 (Tech Stack)

- **Framework:** Django, Django REST Framework (DRF)
- **AI Engine:** OpenAI GPT-4 (via gms_client)
- **Search API:** SerpApi (Google Search Engine)
- **Database:** PostgreSQL / SQLite (Django ORM)
- **Language:** Python 3.x


## 🚀 주요 트러블슈팅 기록 (Issue Log)
Needs/Recommends) 복구
- **문제**: 추천 로직 수정 과정에서 AI 분석 결과인 '분석 이유(Needs)'와 '권장 사양(Recommends)' 데이터가 프론트엔드로 전달되지 않는 현상 발생.
- **해결**: `_normalize_lines` 및 `_dedupe_lines` 유틸리티 함수를 완벽히 복구하여 AI의 응답 텍스트를 정제된 리스트 형태로 프론트엔드에 전달하도록 수정함.


## 🌟 핵심 기능 (Core Features)

### 1️⃣ 지능형 제품 스코어링 & 필터 완화
- 사용자의 요구사항(RAM, 저장공간, 용도 등)을 분석하여 DB 내 제품에 점수를 부여합니다.
- 조건에 부합하는 제품이 적을 경우, 사양 조건을 단계적으로 낮추는 **Filter Relaxation** 로직을 통해 반드시 결과를 제공합니다.

### 2️⃣ 브랜드 다양성 보장 (Deduplication)
- 추천 결과가 특정 브랜드에 편중되지 않도록 브랜드 중복 제거 알고리즘을 적용하여 사용자에게 폭넓은 선택지를 제공합니다.

### 3️⃣ 지능형 링크 매칭 (SerpApi 연동)
- **공식 사이트 우선**: Apple, Samsung, LG 등 브랜드 공식 도메인을 최우선으로 매칭합니다.
- **쇼핑몰 연동**: 다나와, 쿠팡, 네이버 쇼핑 등 주요 커머스 링크를 차순위로 제공합니다.

## 📡 API 명세

### 1. 제품 추천 API

- Endpoint: POST /gms/recommend-computers/
- Request: { "query": "대학생이 쓰기 좋은 가벼운 노트북 추천해줘" }
- Response Content:
    - results: 추천 제품 리스트 (3개)
    - needs: AI가 분석한 사용자 요구 사항 요약
    - recommends: AI가 권장하는 하드웨어 사양

### 2. 시스템 테스트 API

- Endpoint: GET /gms/gms_test/
- Description: OpenAI API 연결 및 서버 상태를 점검합니다.

- services/gms_client.py: OpenAI API 통신 모듈
- models.py: 제품 상세 스펙 모델 (ProductDetailSpec)
