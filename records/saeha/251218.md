# 백엔드 다시 생성하기

- $ python -m venv venv
- $ source venv/Scripts/activate
- $ pip install -r requirements.txt 
    - 주석이 들어가 있으면 안됨 (에러남)
- $ django-admin startproject mrpcpicker . 
    - 프로젝트 이름 : mrpcpicker

---

- $ python manage.py startapp accounts
- $ python ./manage.py startapp community
- $ python ./manage.py startapp parts
- $ python ./manage.py startapp requests
- $ python ./manage.py startapp recommend
    - 앱 이름 : 하나의 역할에 집중된 이름 + 복수형 명사
        - accounts : 회원가입, 로그인, 사용자 정보 처리
        - articles : 게시글, 댓글, 좋아요
        - products : 외부 API 연동, 크롤링, DB 관리
        - gms : GMS 연결

---

- windsurf 분석


- CORS 설정: CORS 관련 설정이 보이지 않습니다. 프론트엔드와 연동 시 필요할 수 있습니다.
- products.Laptop: 노트북 제품 정보를 저장하는 모델입니다. 필드들이 잘 정의되어 있지만, 몇 가지 개선사항이 있습니다:
    - price 필드에 decimal_places와 max_digits를 명시적으로 지정하는 것이 좋습니다.
    - null=True, blank=True가 필요한 필드에만 적용되어 있습니다.
    - products.Laptop 모델에 __str__ 메서드를 추가하면 관리자 페이지에서 더 보기 좋게 표시됩니다.
    - 공통 필드(예: created_at, updated_at)를 위한 추상 모델을 고려해보세요.

-  API 문서화:
    - Swagger나 DRF Spectacular를 사용하여 API 문서를 자동화할 수 있습니다.
