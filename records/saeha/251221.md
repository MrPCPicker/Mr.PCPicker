# 🧠 Mr.PCPicker — AI Laptop Recommendation Assistant

본 문서는 2025년 12월 21일 작업 기준으로 반영된 기능 구현 현황과 완료 내역을 정리합니다.  
Vue + Django + GMS(OpenAI Responses / GPT 5 Nano) 기반으로 구현한 노트북 추천 서비스입니다.

### 💸 모델 선택 & 비용 최적화

| 항목 | 결과 |
|------|------|
| GMS 모델 변경 | `GPT-4.1` → `GPT-5 Nano` |
| 중복 호출 최소화 | Query 입력 시 1회 호출 |
| 프롬프트 길이 최적화 | 불필요 설명 제거 |
| 후보 노트북 수 축소 | token 절약 |
| bullet 자동 제거 | 프론트 처리 |

> GPT 5 Nano는 쇼핑 어시스턴트(상품 비교/스펙 추천) 용도로 충분한 reasoning을 제공하면서 비용이 훨씬 낮습니다.

## 🔍 현재 UX 시나리오

1. 사용자가 자연어 니즈 입력  
2. 검색바 확장 → Search  
3. RecommendView로 이동  
4. GMS가 DB 후보 기반으로 3개 제품 추천  
5. Needs / Recommends / Summary 표시  
6. Query 수정 → rewrite → 즉시 재추천 가능
