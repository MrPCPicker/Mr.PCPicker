# 계정 관련 기능 구현 상세

## 1. 인증 시스템

### 1.1 로그인
```javascript
// AuthService.js
export default {
  async login(username, password) {
    const response = await axios.post(`${API_URL}token/`, { username, password });
    if (response.data.access) {
      localStorage.setItem('user', JSON.stringify(response.data));
      window.dispatchEvent(new Event('auth-changed'));
    }
    return response.data;
  }
};
```

### 1.2 로그아웃
```javascript
// AuthService.js
async logout() {
  localStorage.removeItem('user');
  window.dispatchEvent(new Event('auth-changed'));
  await axios.post(`${API_URL}logout/`);
}
```

### 1.3 회원가입
```javascript
// AuthService.js
async register(name, username, password) {
  const response = await axios.post(`${API_URL}register/`, {
    name,
    username,
    password,
    password2: password
  });
  
  if (response.data.tokens) {
    localStorage.setItem('user', JSON.stringify(response.data));
    window.dispatchEvent(new Event('auth-changed'));
  }
  return response.data;
}
```

## 3. 비밀번호 변경

```javascript
// ProfileView.vue
async changePassword() {
  if (this.passwordForm.newPassword !== this.passwordForm.newPassword2) {
    this.passwordError = '새 비밀번호가 일치하지 않습니다.';
    return;
  }

  try {
    await axios.post(`${API_URL}change-password/`, this.passwordForm);
    this.showPasswordForm = false;
    this.passwordForm = { oldPassword: '', newPassword: '', newPassword2: '' };
  } catch (error) {
    if (error.response?.data?.old_password) {
      this.passwordError = '현재 비밀번호가 틀렸습니다.';
    } else {
      this.passwordError = '비밀번호 변경에 실패했습니다.';
    }
  }
}
```

## 4. 네비게이션 바 상태 관리

```javascript
// Navbar.vue
export default {
  data() {
    return {
      isAuthenticated: !!AuthService.getCurrentUser()
    };
  },
  created() {
    window.addEventListener('auth-changed', this.updateAuthState);
    window.addEventListener('storage', this.updateAuthState);
  },
  methods: {
    updateAuthState() {
      this.isAuthenticated = !!AuthService.getCurrentUser();
    }
  }
};
```

## 7. 백엔드 API 엔드포인트

### 7.1 Django REST Framework 뷰셋
```python
# views.py
class UserViewSet(viewsets.ModelViewSet):
    queryset = User.objects.all()
    serializer_class = UserSerializer
    permission_classes = [IsAuthenticated]

    @action(detail=False, methods=['post'])
    def change_password(self, request):
        user = request.user
        serializer = ChangePasswordSerializer(data=request.data)
        
        if serializer.is_valid():
            if not user.check_password(serializer.data['old_password']):
                return Response(
                    {"old_password": ["현재 비밀번호가 틀렸습니다."]}, 
                    status=status.HTTP_400_BAD_REQUEST
                )
            user.set_password(serializer.data['new_password'])
            user.save()
            return Response({"message": "비밀번호가 성공적으로 변경되었습니다."})
        return Response(serializer.errors, status=status.HTTP_400_BAD_REQUEST)
```
