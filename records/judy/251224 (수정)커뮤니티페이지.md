# Mr.PCPicker 개발 기록

## 2024년 12월 24일 업데이트

### 1. 인증 관련 개선사항

#### 1.1 토큰 자동 갱신 기능 추가
- `AuthService.js`에 `refreshToken` 메서드 구현
- Axios 인터셉터를 통한 자동 토큰 갱신 로직 추가
- 401 에러 발생 시 자동으로 토큰 갱신 시도
- 토큰 갱신 실패 시 자동 로그아웃 처리

#### 1.2 인증 헤더 개선
- 모든 API 요청에 자동으로 인증 헤더 추가
- 토큰 만료 시 자동 갱신 후 재시도 로직 구현
- 콘텐츠 타입 헤더 자동 추가

### 2. 게시판 기능 개선

#### 2.1 카테고리 관련 수정
- 백엔드 `models.py`에 'estimate' 카테고리 추가
- 프론트엔드에서 카테고리 값 소문자로 통일 처리
  ```javascript
  // 변경 전
  category: category.value
  
  // 변경 후
  category: category.value.toLowerCase()
  ```

#### 2.2 게시글 상세 페이지 개선
- 좋아요 기능 개선
  - 좋아요 수 표시 UI 추가
  - 좋아요 상태 즉시 반영
  - 비로그인 시 로그인 페이지로 리다이렉트

- UI/UX 개선
  - 좋아요 버튼 디자인 개선
  - 좋아요 수 표시 스타일링
  - 반응형 디자인 개선

#### 2.3 댓글 기능 개선
- 댓글 작성/수정/삭제 시 UI 즉시 반영
- 댓글 수정 폼 UI 개선
- 권한 없는 사용자에 대한 처리 강화

### 3. 버그 수정
- 401 Unauthorized 오류 해결
- 토큰 만료 시 무한 리다이렉트 문제 해결
- 좋아요 상태 동기화 문제 해결
- 카테고리 대소문자 불일치 문제 해결

### 4. 사용된 기술 스택
- Frontend: Vue.js 3, Vue Router, Axios
- Backend: Django REST Framework, JWT 인증
- Styling: CSS3, Flexbox

### 6. 실행 방법

#### 프론트엔드
```bash
cd frontend/pcpicker-project
npm install
npm run dev
```

#### 백엔드
```bash
cd backend
python manage.py runserver
```

### 7. 참고 사항
- 모든 API 요청은 JWT 인증을 사용합니다.
- 토큰은 5분 후 만료되며, refresh token을 사용해 자동 갱신됩니다.
- 인증 관련 이슈는 `AuthService.js`에서 관리됩니다.
