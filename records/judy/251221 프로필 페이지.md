# 프로필 뷰 컴포넌트 (ProfileView.vue)
이 컴포넌트는 사용자 프로필을 표시하고 관리하기 위한 Vue.js 컴포넌트입니다.
## 주요 기능
1. **프로필 정보 관리**
   - 이름, 이메일 등의 기본 정보 표시 및 수정
   - 프로필 사진 업로드 및 변경
   - 비밀번호 변경 기능
2. **UI/UX 특징**
   - 반응형 디자인 (모바일, 태블릿, 데스크톱 지원)
   - 인풋 필드 유효성 검사
   - 로딩 상태 표시
   - 사용자 피드백 (성공/에러 메시지)
3. **보안 기능**
   - JWT 기반 인증
   - 안전한 비밀번호 변경 프로세스
   - 로그아웃 및 회원 탈퇴 기능

## 스크립트 (Script)

```js
export default {
  data() {
    return {
      isEditing: false,      // 편집 모드 상태
      isSaving: false,       // 저장 중 상태
      showPasswordForm: false, // 비밀번호 변경 폼 표시 여부
      user: {                // 사용자 정보
        profileImage: '',    // 프로필 이미지 URL
        username: '',        // 사용자명
        name: '',           // 이름
        email: ''           // 이메일
      },
      // ... 기타 데이터 속성들
    }
  },
  methods: {
    // 프로필 이미지 변경 핸들러
    handleProfileImageChange(event) {
      // 파일 리더를 사용하여 이미지 미리보기
      const file = event.target.files[0];
      const reader = new FileReader();
      reader.onload = (e) => {
        this.user.profileImage = e.target.result;
        this.updateProfileImage(file);
      };
      reader.readAsDataURL(file);
    },
    // 프로필 저장
    async saveProfile() {
      if (!this.editForm.name.trim()) {
        alert('이름을 입력해주세요.');
        return;
      }
      this.isSaving = true;
      try {
        await AuthService.updateProfile(this.editForm);
        this.user.name = this.editForm.name;
        this.user.email = this.editForm.email;
        this.isEditing = false;
        alert('프로필이 수정되었습니다.');
      } catch (error) {
        console.error('프로필 수정 실패:', error);
        alert('프로필 수정에 실패했습니다. 다시 시도해주세요.');
      } finally {
        this.isSaving = false;
      }
    },
    // ... 기타 메소드들
  }
}
```
