# 상품 검색 페이지 (Product Search Page)

## 개요
이 페이지는 사용자가 상품을 검색하고 필터링할 수 있는 페이지입니다. 상품 목록을 표시하고, 검색, 필터링, 정렬 기능을 제공합니다.

## 주요 기능

### 1. 상품 검색
- 상품명, 브랜드, CPU 정보로 검색 가능
- 실시간 검색 결과 제공

### 2. 필터링
- 브랜드 필터 (Samsung, LG, Apple 등)
- RAM 용량 필터 (4GB, 8GB, 16GB, 32GB, 64GB)
- SSD 용량 필터 (128GB, 256GB, 512GB, 1TB, 2TB)

### 3. 정렬
- 가격순 (낮은 가격순 / 높은 가격순)
- 최신순
- 인기순 (평점 기반)

### 4. 페이지네이션
- 한 페이지에 12개 상품 표시
- 페이지 이동 기능

## 기술 스택
- Vue.js 3
- Vuex (상태 관리)
- Vue Router (라우팅)
- Axios (API 요청)
- Font Awesome (아이콘)

## 컴포넌트 구조
- `SearchView.vue`: 메인 검색 페이지 컴포넌트
- `ProductCard.vue`: 개별 상품 카드 컴포넌트

## API 엔드포인트
- `GET /products/products/`: 상품 목록 조회

## 샘플 데이터
API 요청 실패 시 자동으로 표시되는 샘플 데이터:
1. 삼성 갤럭시북3 프로
2. LG 그램 16
3. 맥북 프로 14
4. LG 울트라PC 15
5. 삼성 갤럭시북2 프로 360

## 실행 방법
1. 프론트엔드 서버 실행:
```bash
cd frontend/pcpicker-project
npm install
npm run dev
```

2. 백엔드 서버 실행:
```bash
cd backend
python manage.py runserver
```

## 참고 사항

- 반응형 디자인 지원 (모바일, 태블릿, 데스크톱)
