# 📋 프로젝트 개발 보고서: 위시리스트 고도화 및 커뮤니티 UI 개선 (12/25)

## 1. 개요
기존의 찜 기능을 '위시리스트'로 전면 개편하고, 전반적인 서비스의 톤앤매너(Tone & Manner)를 프리미엄 다크 네이비 테마로 통일하였습니다. 또한, 커뮤니티 기반의 견적 요청 시스템을 구축하여 정보 가독성을 대폭 향상시켰습니다.

---

## 2. 주요 작업 및 성과

### ✅ 위시리스트(Wishlist) 기능 및 UI 고도화
* **명칭 및 스타일 개편**: '찜목록'을 '위시리스트'로 명칭 변경하고, 전용 스타일을 적용하여 브랜드 이미지를 강화했습니다.
* **배경색 동기화**: Hero 영역 배경을 HomeView와 동일한 **다크 네이비(#2f3a45)**로 통일하여 페이지 전환 시 시각적 일체감을 부여했습니다.
* **정보 집약적 카드 디자인**: 
    * 제품 이미지 크기를 슬림하게 조정하여 한 화면에 더 많은 정보를 담을 수 있도록 최적화했습니다.
    * 노트북 등 복잡한 스펙이 누락되지 않도록 **태그 자동 줄바꿈** 및 전체 리스트 노출 로직을 구현했습니다.
* **인터랙션 유지**: 찜 추가 상태에서도 취소 버튼(-)을 유지하여 사용자가 목록에서 즉시 관리할 수 있도록 사용성을 개선했습니다.
* **커스텀 UI 컴포넌트**: 기본 브라우저 스타일 대신 브랜드 컬러(Blue)가 적용된 **프리미엄 사각 체크박스**를 커스텀 구현했습니다.

### 🌐 커뮤니티 및 견적 시스템 개선
* **견적 요청 페이지 디자인**: 게시글 작성 시 하드웨어 스펙 정보를 포함할 수 있도록 레이아웃을 개선하여 정보 전달력을 높였습니다.
* **접근성 및 가독성 확보**: 
    * 다크 모드 환경에서도 텍스트가 묻히지 않도록 **셀렉트 박스(드롭다운) 배경색**을 별도로 지정하여 가시성을 확보했습니다.
    * 커뮤니티 게시판의 전반적인 입력 폼 디자인을 메인 테마에 맞춰 고도화했습니다.

### 🛠 기술적 해결 내용
* **Flexbox 레이아웃**: 스펙 태그의 유동적인 배치를 위해 CSS Flex-wrap 속성을 활용한 자동 줄바꿈 시스템 구축.
* **UI 일관성 유지**: 전역 CSS 변수 및 컴포넌트 스타일 수정을 통해 페이지별 상이했던 배경색과 폼 요소들의 디자인 통일.
